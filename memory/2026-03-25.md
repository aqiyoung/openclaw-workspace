## Gateway 重启通知自动化
- 问题：Gateway 重启时进程被 SIGTERM 杀掉，无法自动发通知
- 解决方案：systemd timer + bash 脚本
  - 脚本：`~/.openclaw/check-restart-notify.sh`
  - Timer：每 15 秒检测 Gateway 启动时间变化
  - 零 token 消耗，纯系统级监控

## NAS 监控系统
- 需求：监控 NAS 访问 IP、SSH 登录记录、性能告警
- 解决方案：systemd timer + bash 脚本
  - 脚本：`~/.openclaw/nas-monitor.sh`
  - Timer：每 5 分钟检查一次
  - 监控内容：
    1. 新设备发现（arp 表扫描）
    2. NAS 连接记录（192.168.31.58）
    3. CPU > 90% 告警
    4. 内存 > 85% 告警
    5. 磁盘 > 90% 告警
  - 告警恢复也会通知
  - 零 token 消耗
