- **原因：** 代理对微信 API 的 POST 请求有影响
- **解决：** 用 Python urllib 直连调用，不走代理
- **正确 AppSecret：** `31dd5e8ce9bf116d1b5ca3b81c2d82ea`（在 check_wechat_ip.sh 和 MEMORY.md 里）

import json
import os

# 必须不走代理
os.environ.pop('https_proxy', None)
os.environ.pop('http_proxy', None)

appid = "wx97bc84bb54232e27"

# 获取 token
