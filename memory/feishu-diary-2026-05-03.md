### Feishu API 网络不可达 ❌

- **问题**: 飞书开放平台API (open.feishu.cn) 无法从服务器访问
- **原因**: 服务器所有出口流量通过 mihomo 代理（全部为海外节点），GFW 阻断了海外节点到 feishu.cn 国内 CDN 的 TLS 连接
- **尝试的解决方案**:
  - curl/wget 直连 → 超时（无直接网络）
  - curl 通过 HTTP 代理 → SSL 握手失败（GFW RST）
  - Node.js 原生 HTTPS → 超时
  - Python requests → SSL 连接关闭
  - undici ProxyAgent → ECONNRESET
  - 修改 mihomo 配置添加 DOMAIN-SUFFIX 直连规则 → 无效（CONNECT 隧道成功但 TLS 仍被 reset）
- **需要的解决方案**:
  - 在 mihomo 中添加国内代理节点
  - 或配置 feishu.cn 走直连（需要服务器有直接出站能力）
  - 或使用飞书的国际版 API (open.larksuite.com)
