## 模型提供商清理（2026-09-11）

**问题**：app 设置里「模型提供商」页面显示一堆「没有可用模型」的空 provider（amd/bynara/dahl/jianzhile/k12/minimax/qystart/tokenrouter/xrelayai/zyloo）。

**根因**：这些 provider 的 API key 存在 auth 注册表（`openclaw-agent.sqlite`）里，但模型列表在 `openclaw.json`/`models.json` 里被清掉了 → auth 注册了名字、模型却空了。

**排查方法**：
- `openclaw models list` — 看实际加载的模型
- `openclaw models status` — 显示 provider 的 auth 来源（profiles/env）
- `openclaw models auth list` — 列出所有注册过的 auth profile

**修复**：`openclaw models auth logout <profile> --yes` 批量删除空 provider 的 profile。

**保留（4 个在用）**：dots、nvidia、openrouter、sensenova

**删除（13 个空壳 profile）**：amd、bynara、dahl×2、jianzhile、k12、minimax×3、qystart、tokenrouter、xrelayai、zyloo

**教训**：
- 空 provider 不来自配置文件，来自 auth 注册表残留 → 删配置不够，要删 auth profile
- `logout` 需要 `--yes` 才能非交互删除，否则拒绝
- 后台批量命令可能被 SIGTERM 中断，删到一半 → 每次删完查一遍 `auth list` 确认
- `openclaw models auth list` 是排查 provider 空壳的关键命令
