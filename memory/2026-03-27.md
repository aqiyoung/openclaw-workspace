## 技术笔记

### TTS 配置路径
- 配置文件：`~/.openclaw/openclaw.json`
- 关键字段：`messages.tts.auto`（off/always/inbound/tagged）
- Edge TTS 不需要 API 密钥

### mihomo 配置路径
- 配置文件：`~/.config/mihomo/config.yaml`
- 启动命令：`mihomo -d ~/.config/mihomo`
- 重载：`kill -HUP $(pgrep mihomo)` 或重启进程

### WARP 状态检查
- `warp-cli status` — 连接状态
- `warp-cli connect` / `warp-cli disconnect` — 连接/断开
- SOCKS5 代理：127.0.0.1:40000
