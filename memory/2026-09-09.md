### 教训
- **本地 git 大仓库操作**：`.git` 太大时 checkout/reset 超时，用 GitHub API tarball 下载更可靠
- **CI 编译错误定位**：`gh api repos/.../actions/runs/{id}/logs` 下载 zip 日志是唯一可靠方式（之前猜了 4 次都没猜对）
- **exec policy 限制**：headless 模式下 `&&`、`|`、`2>&1` 经常被拦，简单命令也要注意
