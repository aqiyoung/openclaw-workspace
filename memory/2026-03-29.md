### 关键教训

1. **代码块样式**：用 `<pre style="background:#1e1e1e;color:#d4d4d4;padding:14px 18px;border-radius:8px;font-family:Menlo,Consolas,monospace;font-size:14px;line-height:1.6;overflow-x:auto;margin:10px 0">`（GitHub 暗色风格），不要用截图
2. **封面图**：2400×1350 高清，用 PIL 生成（不用 Playwright，有字体问题）
3. **终端截图**：用 `el.screenshot()` 截终端元素（不带黑边框），`device_scale_factor=2` 保证高清
4. **列表**：不用 `<ul><li>`（有圆点序号），用 `<p>` 段落
5. **文章末尾**：关注引导卡片 + 往期推荐（不加链接，微信 API 拦截外部 URL 导致报错 45166）
6. **IP 白名单**：微信公众号 API 需要 IP 白名单，当前 IP 111.19.33.189
7. **微信 WAF**：draft/update 接口对长 content 有 WAF 拦截（501），某些关键词会触发（如 DNS 配置、curl 安装命令）

## 封面图系统重建

- **问题**：Playwright 截图中文有方块（字体渲染问题），emoji 在 PIL 里渲染成方块
