## 晚上 — OpenClaw Android ChatComposer 附件控件优化

- **问题**：用户说左边 3 个图标（图片/文件/视频）太占空间，输入框挤得没地方了
- **上游检查**：官方 `v2026.7.1` 没有优化，跟用户 fork 代码一样
- **迭代过程**（多轮折腾）：
  1. ❌ 3 图标 → 1 个 `+` 按钮 + DropdownMenu → 颜色不统一（浅紫色），用户说丑
  2. ❌ DropdownMenu 去掉文字，宽度还是大 → 用户说留太宽
  3. ❌ 用 `Popup` 悬浮 → 定位不对，用户说变形、向下了
  4. ❌ `Popup alignment = BottomStart` → 还是丑，用户说恢复官方
  5. ❌ 恢复官方 → 用户说输入框还是没空间
  6. ✅ **最终方案**：`ModalBottomSheet` — Material3 原生组件，干净好看，点击 `+` 弹出底部弹窗，选图片/文件/视频
- **版本号坑**：用户说 3 次版本号没更新，根因是 `Config/Version.properties` 和 `version.json` 两处都要改，且 `version.json` 的 `version` 和 `versionCode` 要同步
- **最终构建**：v2026.8.3.0，版本号显示 `2026.8.3`
- **教训**：Android 版本号要同时改 `version.json` 和 `Config/Version.properties`，否则 CI 读的版本不对
