#### 认证流程（供下次参考）
1. `gog auth add <email> --services gmail,drive,calendar,contacts,sheets,docs --remote --step 1 --force-consent --redirect-uri "https://nas.threel.site/oauth2/callback"` → 获取认证 URL
2. 老板在浏览器打开 URL，用 Google 账号登录并授权
3. Google 回调到 `https://nas.threel.site/oauth2/callback` → nginx 反代到 `127.0.0.1:39059` → Python HTTP server 接收 code
4. 老板把回调 URL 发回来
5. `gog auth add <email> --remote --step 2 --auth-url <callback_url> --redirect-uri "https://nas.threel.site/oauth2/callback" --force-consent` → 完成认证

#### 关键配置
- **nginx 反代**：`/etc/nginx/conf.d/nas.threel.site.conf` 里有 `/oauth2/callback` → `127.0.0.1:39059`
- **HTTP server**：临时 Python server 监听 39059 端口接收回调
- **redirect_uri**：必须用 `https://nas.threel.site/oauth2/callback`（Google 接受的域名）

### 🔧 Scrapling CLI 工具
**安装位置**：`/vol1/1000/wechat-backup/venv/`
**入口命令**：`source /vol1/1000/wechat-backup/venv/bin/activate && scrapling`

**CLI 命令：**
1. `scrapling extract` - 抓取网页并提取内容
   - 支持 CSS 选择器
   - 支持 AI 智能提取（--ai-targeted）
   - 输出格式：.html / .md / .txt
   - 参数：--headers, --cookies, --params, --json, --proxy
   - 示例：`scrapling extract https://example.com -o result.html`

2. `scrapling shell` - 交互式爬虫控制台
   - 支持直接执行 Python 代码
   - 参数：-c/--code（执行代码后退出）, -L/--loglevel

3. `scrapling mcp` - MCP 服务器模式
   - 支持 stdio 和 streamable-http 传输
   - 参数：--http, --host, --port
   - 示例：`scrapling mcp --http --port 8000`

4. `scrapling install` - 安装所有依赖

**核心模块：**
- `Fetcher` - 基础 HTTP 请求（基于 curl_cffi）
- `StealthyFetcher` - 隐身浏览器抓取（基于 Chromium，绕过反爬虫）
- `DynamicFetcher` - 动态页面抓取
- `Selector` - CSS/XPath 选择器

**使用示例：**
```python
from scrapling.fetchers import Fetcher, StealthyFetcher

# 基础抓取
page = Fetcher().get("https://example.com")
titles = page.css("h1::text").getall()

# 隐身抓取（绕过 Cloudflare）
page = StealthyFetcher().get("https://example.com")
content = page.css(".content").get()
```
