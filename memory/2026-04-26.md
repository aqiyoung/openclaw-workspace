## Wechat Article Auto Skill Improvements

### Logo Sizing Strategy
- Final solution: Unified height (160px) with proportional width scaling
- Better than fixed square box approach for logos with different aspect ratios
- Logos displayed horizontally above title

### Summary Extraction Timing
- Must extract summary from Markdown stage, not HTML stage
- Extracting from HTML captures `<style>` CSS blocks causing garbled text
- Moved extraction logic from `create_draft` (HTML) to `process_article` (Markdown)

### Default Behavior Reversal
- `--no-deai` → `--deai` (de-ai disabled by default)
- `--no-meta` → `--with-meta` (template decoration disabled by default)
- "Clean mode" is now default behavior
- Users must explicitly pass flags to enable extra features

### Modern Typography
- Notion/Typora style adopted
- h1: 32px, h2: 26px, h3: 22px
- Body: 17px, line-height 1.9, paragraph spacing 40px
- Bold: 700 weight, 18px, pure black
- Code blocks: dark background + rounded corners
- Quote blocks: light gray background + left border
- Auto-bold detection for "short sentences ending with Chinese colon" (e.g., "核心亮点：")
- Converter outputs pure HTML, template controls all styles

### Style Separation Strategy
- Converter outputs pure HTML without embedded CSS
- Template controls all styling to avoid conflicts
- no_meta=True still applies template styles, only removes header/footer decoration
