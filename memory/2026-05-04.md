### "No further response from me" 消息来源确认
- 来源：OpenClaw Telegram bot 模块（bot-etaDTLyM.js）
- 触发条件：当 OpenClaw 处理了请求但没有发送任何回复时，自动发送 fallback 消息
- 常见场景：子 Agent 完成任务无回复、Cron 任务无输出、消息处理异常
- 这是 OpenClaw 内置机制，不是 AI 主动发送的
- 解决方案：配置 suppressSilentReplyFallback: true 可禁用
