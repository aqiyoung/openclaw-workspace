### 问题迭代

- v1.7 (进行中): JS 自动填入 Token + 点击连接按钮，CSS 隐藏横幅，多次重试

### 关键技术发现
- OpenClaw 控制台是 **Lit Web Component**（`<openclaw-app>`）
- 控制台登录页是 SPA 内部组件，不是单独 HTML 页面
- Token 通过 `applySettings({token: 'xxx'})` 设置
- WebSocket 连接建立后用 `Authorization: Bearer <token>` 调用 API
- 登录表单 CSS 类名：`.login-gate`, `.login-gate__header`, `.login-gate__card`
- 控制台 JS 文件：`index-BUB744L7.js`（压缩）

### 用户反馈
- 登录页太鸡肋（输入 Token 后还要在控制台再登录一次）
- Token 没有自动填入控制台登录页
- "OpenClaw Control" 悬浮条一直显示（CSS 选择器没命中，因为是 Shadow DOM）
- 要求代码中不出现任何硬编码域名

### GitHub Actions 构建
- Release 步骤一直失败：`Resource not accessible by integration`
- 需要在仓库 Settings → Actions → General → Workflow permissions → Read and write permissions
- APK 构建本身成功，只是 Release 发布失败
- 使用 `gh run download` 手动下载 artifact

### 待解决
- [ ] 控制台悬浮条隐藏（Shadow DOM 隔离，CSS 无法穿透）
- [ ] Token 自动填入并连接（需要等 SPA 渲染完成后操作 DOM）
