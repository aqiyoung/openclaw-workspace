## 微信 API 踩坑记录

### 字节长度限制（不是字符数！）
- **标题**：最多 64 字节（UTF-8），中文一个字 = 3 字节
- **摘要**：最多 120 字节（UTF-8）
- **作者名**：约 30 字节（实测，微信未明确说明）
- **解决方法**：截断时按 `len(text.encode('utf-8'))` 计算，而不是 `len(text)`

### JSON 序列化问题
- **问题**：`requests.post(url, json=data)` 默认用 `json.dumps(data, ensure_ascii=True)`，中文字符被转成 `\uXXXX`
- **解决**：手动序列化，`json.dumps(data, ensure_ascii=False, separators=(',', ':'))`，然后 `data=json_str` 配合 `headers={'Content-Type': 'application/json; charset=utf-8'}`
- 或者更简单：用 `data=json.dumps(data, ensure_ascii=False).encode('utf-8')`

### IP 白名单
- 微信公众平台 IP 白名单只认 IPv4 地址
- 如果服务器有 IPv6 出口，可能被误判为“未授权 IP”（错误码 40164）
- 当前服务器公网 IPv4：`111.19.38.90`（已配置）
- 注意：服务器还有 IPv6 地址（如 `2409:8a70:1046:c010::4d7`），但不影响，只要请求走 IPv4 就行
